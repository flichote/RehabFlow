# RehabFlow 核心交互流程

- 版本：v0.1（初始规划）
- 配套文档：`PRD.md`（需求）、`design-system.md`（token）、`pages.md`、`components.md`

> 流程用「角色 → 动作 → 系统响应」描述，覆盖 V2 核心闭环。开发实现时以本流程为交互验收依据。

---

## 流程 1：排课（管理员核心）

### 1.1 拖拽排课（标准路径）

```text
管理员打开 /admin/scheduler（默认周视图，周一起始）
  → 左侧/右侧「待排患者池」选择患者卡片
  → 拖拽到目标资源（康复师）的空白时间段
  → 松手触发后端冲突检测（事务内）：
      ├─ 无冲突 → 课程创建成功 → 卡片落位 + Toast「排课成功」
      └─ 有冲突 → ConflictDialog 弹窗：
            ├─ 查看详情 → 高亮冲突块
            ├─ 强制替换 → 覆盖冲突课程（写审计日志）
            └─ 取消 → 卡片回弹，不创建
  → 排课成功后系统自动推送提醒（患者 + 康复师，站内信）
```

**验收点**：
- [ ] 15 分钟粒度（9:00 / 9:15 / 9:30…）
- [ ] 患者冲突与康复师冲突分别检测、分别提示
- [ ] 两个管理员同时排同一时段 → 只有一个成功（事务 + 行锁）

### 1.2 双击新建（表单路径）

```text
双击空白格子 → CourseDrawer（新建模式，预填时间/资源）
  → 填写：患者、课程类型、时长、治疗室
  → 保存 → 同上冲突检测逻辑
```

### 1.3 修改 / 取消课程

```text
点击课程卡片 → CourseDrawer（详情模式）
  ├─ 修改时间 → 重新冲突检测 → 变更成功 → 强提醒患者+康复师
  ├─ 取消课程 → ConfirmDialog 二次确认 → 取消 → 通知双方
  └─ 发送提醒 → 立即推送「上课提醒」
```

## 流程 2：上课执行（康复师核心）

### 2.1 一节课程的完整生命周期

```text
课前 15 分钟：系统自动提醒（浏览器弹窗）→ 课程状态「提醒已发」，患者「前往途中」
康复师打开 /therapist/schedule
  → 课程卡片显示「开始上课」按钮
  → 点击「开始上课」：
      课程状态 → 进行中（记录 actual_start_at）
      患者状态 → 治疗中，位置 → 对应治疗室
  → 课程进行中：当前条目高亮闪烁
  → 点击「结束上课」：
      课程状态 → 已完成（记录 actual_end_at，自动算课时）
      患者状态 → 在病房
  → 可选：点「填写记录」→ SessionNoteModal 补治疗记录
```

**异常分支**：
```text
课程时间结束仍未被点击开始
  → 系统自动标记「异常」→ 主任看板 AlertFeed 实时出现
  → 康复师/主管医生收到站内信 + 待办红点
课程结束后 30 分钟患者状态仍为「治疗中」（忘记点结束）
  → 系统巡检 → 推送康复师「是否忘记结束课程？」
```

**验收点**：
- [ ] 开始/结束均记录实际时间
- [ ] 课时消耗自动计算（结束时间 − 开始时间，向上取整到 15 分钟？—— TBD，PRD §9）
- [ ] 异常自动标记不依赖人工

## 流程 3：患者位置追踪（软打卡）

```text
日常路径（全自动）：
  开始上课 → 位置=治疗室      结束上课 → 位置=病房
异常路径（人工修正）：
  患者临时外出检查
    → 医生打开患者 360° → 手动修正位置表单
    → 选择位置 + 备注 → 保存
    → 写入 patient_status_log + 位置卡片刷新
```

**验收点**：
- [ ] 位置变更全部记录审计日志（谁、何时、从哪到哪）
- [ ] 医生只能修正自己名下患者（权限隔离）

---

## 流程 4：异常预警闭环

```text
触发（任一）：
  ├─ 课程超时未开始 → 自动标记异常
  ├─ 康复师标记患者缺席
  └─ 排课冲突未处理（强制替换被拒绝后留存）
    → 主任看板 AlertFeed 实时推送（未处理红条）
    → 管理员打开 /admin/alerts
    → 处理：确认 / 忽略 / 转排
    → 处理完成 → 看板预警消失，写入审计
```

---

## 流程 5：患者端课程可见性

```text
患者登录 → /patient（今日课程概览 + 提醒）
  → /patient/schedule（周历视图，蓝色=我的课程）
  → 点击某天 → 当日课程明细
  → 接收上课提醒（站内信 / 浏览器弹窗）
```

---

## 流程 6：主任看板数据流

```text
实时（30s 轮询 / SSE）：
  今日在院患者总数 / 已排课程总数 / 治疗中人数 → KPI 卡
  患者分布（病房/PT/OT/ST）→ 环形图
  异常预警 → AlertFeed
低频：
  治疗师今日课时 → 柱状图（30min）
  近 7 天课程总量 → 折线图（每日）
```

---

## 流程 7（支撑）：账号与角色

```text
注册 → 选角色（患者/康复师/医生）
  → 管理员审批康复师/医生资质（管理端审核列表）
  → 登录 → middleware 按角色路由 → 对应落地页
```

## 状态流转速查（开发对照）

| 动作 | 课程状态 | 患者状态 | 患者位置 |
| :--- | :--- | :--- | :--- |
| 排课成功 | 待执行 | 待排课 | — |
| 提醒发出（-15min） | 提醒已发 | 前往途中 | — |
| 开始上课 | 进行中 | 治疗中 | 对应治疗室 |
| 临时暂停 | 进行中 | 暂停 | 治疗室 |
| 结束上课 | 已完成 | 在病房 | 病房 |
| 标记缺席 | 未完成-缺席 | 缺席 | 病房 |
| 超时未开始 | 异常 | — | — |
