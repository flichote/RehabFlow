# RehabFlow 设计系统（Design System）

- 版本：v0.1（初始规划）
- 状态：待评审
- 技术基座：Next.js App Router + Tailwind CSS + shadcn/ui 风格
- 更新日期：2026-08-05

> 本文档是 RehabFlow UI 的**唯一事实来源**。所有页面（`pages.md`）与页面组件（`components.md`）必须引用本文档中的 token，禁止在页面中硬编码设计值。

---

## 1. 设计理念

**关键词**：专业、高效、实时、秩序。

- **与 CCN 的视觉区分**：CCN（延续康护）使用蓝绿 teal 传达"院外康复的温暖关怀"；**RehabFlow 使用靛蓝 indigo 传达"院内调度台的秩序与实时"**——场景从"关怀"切换到"执行"。
- **专业与秩序**：靛蓝主色 + 深色文字 + 高对比网格，服务高频操作场景（排课、点课），信息密度高于 CCN。
- **实时与流动**：状态用色块 + 动画表达（当前课程闪烁、状态徽章、位置卡片），呼应产品名"Flow"。
- **课程类型三色语义**（PRD 约定，全局唯一映射）：**蓝-PT / 绿-OT / 橙-ST**，所有页面必须一致。
- **克制**：大屏（排课/看板）信息密度高但视觉分级清晰；移动端仅保留课表与提醒。

## 2. 色彩（Color）

### 2.1 品牌主色（Primary — 靛蓝 Indigo）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--primary-50` | `#EEF2FF` | 主色浅底（选中背景、Tag 底色、表格 zebra） |
| `--primary-100` | `#E0E7FF` | 浅色底（信息卡片、hover 背景、网格描边） |
| `--primary-200` | `#C7D2FE` | 描边、图表浅色系、拖拽占位 |
| `--primary-500` | `#6366F1` | 次级强调（链接、图标、进度条） |
| `--primary-600` | `#4F46E5` | **主行动色**：主按钮、选中态、活跃导航 |
| `--primary-700` | `#4338CA` | 主按钮 hover、按压态 |
| `--primary-800` | `#3730A3` | 深色强调（页头标题、强调文本） |

对应 Tailwind 映射：`primary-50/100/200/500/600/700/800`。

> ⚠️ 这三个颜色是 RehabFlow 的**第一语义**，优先级高于品牌色。任何课程相关 UI 必须使用。

| Token | 色值 | 语义 | 用途 |
| --- | --- | --- | --- |
| `--pt-500` | `#3B82F6` | **PT（物理治疗）** | 课程卡片底色、PT 徽章 |
| `--ot-500` | `#22C55E` | **OT（作业治疗）** | 课程卡片底色、OT 徽章 |
| `--st-500` | `#F97316` | **ST（言语治疗）** | 课程卡片底色、ST 徽章 |

配套浅底：`pt-50` `#EFF6FF` / `ot-50` `#F0FDF4` / `st-50` `#FFF7ED`（卡片浅底 + 深色字组合时使用）。

## 3. 字体（Typography）

| Token | 字号/字重 | 用途 |
| --- | --- | --- |
| `display` | 30px / 700 | 看板 KPI 大数字 |
| `h1` | 24px / 700 | 页面标题 |
| `h2` | 18px / 600 | 区块标题、卡片标题 |
| `h3` | 16px / 600 | 子区块标题 |
| `body` | 14px / 400 | 正文 |
| `body-sm` | 13px / 400 | 辅助文本、表格 |
| `caption` | 12px / 500 | 徽章、时间标签、图例 |
| `mono` | 13px | 时间、课时等数字（tabular-nums） |

- 数字一律使用 `tabular-nums`（等宽数字），保证课表/看板数字对齐。

## 4. 圆角 / 阴影 / 间距

| Token | 值 | 用途 |
| --- | --- | --- |
| 圆角 `radius-sm/md/lg` | 6 / 8 / 12 px | 按钮 / 卡片 / 抽屉 |
| 阴影 `shadow-card` | `0 1px 3px rgba(15,23,42,.08)` | 普通卡片 |
| 阴影 `shadow-pop` | `0 8px 24px rgba(15,23,42,.12)` | 弹窗、抽屉、拖拽浮层 |
| 间距基准 | 4px 栅格（4/8/12/16/24/32） | 全局 |

## 5. 动效（Motion）

| 场景 | 动效 |
| --- | --- |
| 当前课程高亮 | 边框闪烁：`animate-pulse` + `ring-2 ring-primary-500` |
| 状态变更 | 位置卡片数值切换时 300ms fade |
| 拖拽排课 | 拖起时 `shadow-pop` + 120% 缩放；松手冲突时卡片抖动 + 红色描边 |
| 抽屉/弹窗 | 300ms 滑入（右滑）/ 缩放淡入 |
| 看板预警 | 新警报进入列表：左侧红条滑动入场 |

---

## 6. 布局栅格

- **排课日历**：左侧资源栏 240px（可折叠至 48px）+ 右侧时间轴网格（时间列 64px，资源行 ≥ 120px）。
- **课表页**：单列清单，最大宽度 720px 居中，适合快速扫读。
- **患者 360**：左信息栏 320px + 右内容区（Tab 切换）。
- **主任看板**：12 栅格网格——顶部 KPI 通栏 ×4（每格 3 列）、中部三栏（4/4/4）、底部趋势图（12 列全宽）。
- **管理端**：桌面优先，内容区 `max-w-[1400px] mx-auto`。

---

## 7. 图标与图表

- 图标：lucide-react（与 CCN 一致，降低迁移成本）。
- 图表：看板图表族（环形图/柱状图/折线图）统一封装 `ChartCard` 组件，图表库待定（recharts 候选）。
- 图表配色直接引用 `pt/ot/st/primary/neutral` token，不使用额外色板。

---

## 8. 设计约束（Do / Don't）

- ✅ 课程类型三色（蓝/绿/橙）全局唯一，不挪用做其他语义。
- ✅ 状态徽章颜色必须与 §2.3 一致。
- ❌ 不使用 CCN 的 teal 主色（`#14B8A6` 系）——两项目视觉必须可区分。
- ❌ 不在页面中硬编码色值，一律走 token。
- ✅ 高频操作按钮（开始上课/结束上课）使用 `primary-600`，位于卡片右侧或底部。
