# RehabFlow 页面级组件规范

- 版本：v0.1（初始规划）
- 配套文档：`design-system.md`（token）、`pages.md`（页面结构）
- 技术基座：Next.js App Router + Tailwind + shadcn/ui 风格组件

> 组件命名与职责以本文档为准；新组件须先在此登记再实现。

---

## 0. 全局布局组件

### 0.1 AppShell（患者/康复师/医生共用）

- 桌面：Sidebar 240px（导航项高亮 `primary-600` 左侧 3px 指示条）+ Topbar 64px + 内容区。
- 移动：Topbar 56px（汉堡菜单）+ TabBar 56px。
- Topbar 右侧：通知铃铛（未读红点）+ 用户头像菜单。

### 0.2 AdminShell（管理端）

- Sidebar 240px + Topbar + 内容区 `max-w-[1400px]`。
- Sidebar「异常预警」项：未处理数量角标（`danger-500` 红底白字圆角 pill）。

## 2. 排课引擎（管理端核心）

### 2.1 排课日历 `/admin/scheduler`

**布局**：左资源栏（240px，可折叠）+ 右时间轴网格；顶部工具条。

| 区域 | 组件 | 说明 |
| :--- | :--- | :--- |
| 顶部工具条 | 组别筛选（全部/PT/OT/ST SegmentedControl）+ 日/周/月切换 + 今日按钮 + 待排患者池开关 | 默认周视图，周一起始 |
| 左资源栏 | 资源行列表（康复师分组 → 治疗室），可折叠 | 分组头可展开/收起 |
| 时间网格 | `ScheduleGrid` | 行=资源，列=时间（15min 粒度），当前时间线红色竖线 |
| 待排患者池 | 右侧可折叠面板，列出未排课患者 | 拖拽卡片到网格 |

**交互**：
- 拖拽 `CourseCard` 到空白格子 → 松手调 `POST /courses`（后端事务内做双重冲突检测）。
- 冲突 → `ConflictDialog` 弹窗（查看详情 / 强制替换 / 取消）。
- 双击空白格子 → `CourseDrawer` 新建模式。
- 点击课程卡片 → `CourseDrawer` 详情模式。
- 超时未开始的课程 → 卡片置灰 + 右上角 `danger-500` 警示角标。

### 2.2 课程详情抽屉 `CourseDrawer`

- 右滑出面板（480px，`shadow-pop`）。
- 内容：患者信息摘要、课程类型徽章、时间（15min 步进选择器）、治疗室、康复师。
- 操作：保存修改 / 取消课程（二次确认弹窗）/ 填治疗记录入口 / 发送提醒按钮。
- 状态区：课程状态徽章 + 实际开始/结束时间（若已发生）。

### 2.3 冲突弹窗 `ConflictDialog`

- 提示文案：「该时间段已被占用，是否查看详情？」
- 展示冲突明细：患者同时段课程 / 康复师同时段课程（高亮冲突块）。
- 按钮：查看详情 / 强制替换（`danger-500`）/ 取消。

## 3. 我的课表（康复师核心）

### 3.1 课表页 `/therapist/schedule`

| 区域 | 组件 | 说明 |
| :--- | :--- | :--- |
| 顶部 | `TodayOverviewCard` | 今日总课时 / 已完成 / 剩余，三数字横向排列，`tabular-nums` 大字 |
| 主体 | `TimelineList` | 按时间升序的课程条目流 |
| 空隙 | 空闲时段标签 | 灰色 `neutral-400` 虚线标签「空闲 45 分钟」，点击 → 快速新建 |

**时间线条目**（`ScheduleItem`）：

```
[10:00-10:45] [PT徽章] 张三     PT-1室    [铃铛] [填写记录] [开始上课]
```

- 当前进行中：卡片 `ring-2 ring-primary-500` + 边框闪烁动画。
- 状态徽章：待执行（neutral）/ 前往途中（warning）/ 治疗中（success）/ 暂停（warning）/ 缺席（danger）/ 异常（danger）。
- 主操作「开始上课」→ 变「结束上课」（`primary-600`），完成后按钮消失，显示实际时长。

### 3.2 治疗记录模态框 `SessionNoteModal`

- 字段：本次治疗内容（textarea）/ 患者反应（textarea）/ 下次注意事项（textarea）。
- 必填校验：治疗内容必填；提交后课程可标记完成。
- 复用：患者 360° 页查看历史记录入口。

## 4. 患者 360° 视图

### 4.1 页面 `/doctor/patients/[id]`（医生/康复师共用）

**布局**：左信息栏 320px + 右 Tab 区（概览 / 评估记录）。

| 区域 | 组件 | 说明 |
| :--- | :--- | :--- |
| 左栏顶部 | 基本信息卡 | 姓名、年龄、诊断、入院日期、主管医生、责任康复师 |
| 左栏中部 | `PatientLocationCard` | 大号状态文字「当前位于：PT大厅2号床」+ 状态徽章；变更时 300ms fade |
| 左栏底部 | 快捷操作 | 手动修正位置（医生，弹表单）/ 联系康复师 |
| 右 Tab-概览 | `PlanTimeline` | 课程记录时间倒序；圆点：绿=已完成 / 灰=待执行 / 红=缺席 |
| 右 Tab-概览 | `WeekCalendar` | 小型周历，7 天课程分布；点击某天展开当日详细时间表 |
| 右 Tab-评估 | `AssessmentList` + `AssessmentTrendChart` | 量表列表（Fugl-Meyer / Barthel…）+ 趋势折线图 |

### 4.2 手动修正位置表单

- 字段：位置选择（治疗室下拉 / 病房楼层床位）/ 备注。
- 权限：仅 doctor；操作写入 `patient_status_log` 审计。

## 5. 主任看板

### 5.1 看板页 `/admin/dashboard`

12 栅格布局（`grid grid-cols-12 gap-4`）：

| 区域 | 栅格 | 组件 | 刷新 |
| :--- | :--- | :--- | :--- |
| 顶部通栏 | col-span-3 ×4 | `KpiCard` | 实时（轮询 30s） |
| 左栏 | col-span-4 | `DonutChart`（患者分布：病房/PT/OT/ST） | 实时 |
| 中栏 | col-span-4 | `BarChart`（治疗师今日课时） | 30min |
| 右栏 | col-span-4 | `AlertFeed`（异常预警滚动列表） | 实时推送（SSE 候选） |
| 底部 | col-span-12 | `LineChart`（近 7 天课程总量） | 每日 |

**KpiCard**：`display` 字号大数字 + 标签 + 可选趋势箭头（↑↓）。

**AlertFeed**：每条：图标（类型）+ 摘要 + 时间 + 状态（未处理/已处理）；未处理项左侧 `danger-500` 3px 竖条 + 入场滑动动画；点击跳 `/admin/alerts` 处理。

## 6. 通用组件

| 组件 | 说明 |
| :--- | :--- |
| `StatusBadge` | 状态徽章；色值映射见 design-system §2.3 |
| `CourseTypeBadge` | 课程类型徽章（PT 蓝 / OT 绿 / ST 橙）；带图标 |

| `ScheduleGrid` | 排课时间轴网格（核心，见 2.1） |
| `TimelineList` / `ScheduleItem` | 课表时间线（见 3.1） |
| `PatientLocationCard` | 实时位置大卡片 |
| `ChartCard` | 图表容器：标题 + 刷新频率角标 + 图表区 |
| `EmptySlot` | 空闲时段标签（课表页） |
| `ConfirmDialog` | 通用二次确认（取消课程 / 强制替换等） |

## 7. 错误与边界状态

| 场景 | 表现 |
| :--- | :--- |
| 网格加载中 | 骨架屏（时间网格灰色 shimmer） |
| 无课程的空闲日 | 课表页显示空状态插画 + 「暂无课程」 |
| 冲突弹窗已打开 | 网格中冲突课程块高亮描边，其余可继续操作 |
| 网络错误 | Toast 提示 + 操作按钮保留重试 |
